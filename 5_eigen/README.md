# Unit 5: Eigenvalue problems
This directory contains several examples used in Unit 5 on eigenvalue problems.

## The `5_eigen.ipynb` notebook

The Python notebook contains the same code and functionality in the Python scripts below. It combines the scripts into an interactive format, making it easier to run, visualize results, and make modifications directly within the notebook environment.

## Lecture 26: Eigenvalue problems

### The `square_eig.py` example

This program demonstrates Python's "eigs" function for finding the eigenvalues and eigenvectors of a sparse matrix. It also calculates fundamental mode vibrations on a square drum, described by the 2D wave equation. The program can be run by typing the following command in the terminal:

```Shell
python3 square_eig.py
```

## Lecture 29: Power method

### The `power.py` example

This program demonstrates the shifted power method for extracting an eigenvector of a matrix. The program can be run by typing the following command in the terminal:

```Shell
python3 power.py
```

## Lecture 30: Inverse iteration, Rayleigh quotient

### The `inverse_iter.py` example

This program demonstrates the inverse shifted power iteration for estimating eigenvalues. The program can be run by typing the following command in the terminal:

```Shell
python3 inverse_iter.py
```

### The `rayleigh_iter.py` example

This program demonstrates the Rayleigh quotient method for rapidly estimating an eigenvalue. The program can be run by typing the following command in the terminal:

```Shell
python3 rayleigh_iter.py
```
