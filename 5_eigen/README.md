## Lecture 26: Eigenvalue problems

### The `square_eig.py` example

This program demonstrates Python's "eigs" function for finding the eigenvalues and eigenvectors of a sparse matrix. It also calculates fundamental mode vibrations on a square drum, described by the 2D wave equation. The program can be run by typing the following command in the terminal:

```Shell
python3 square_eig.py
```
